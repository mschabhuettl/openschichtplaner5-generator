# 0.8.3 – Optionale automatische Dienstfreigaben aus Historie

Beim Datei- oder API-Import kann **Wiederholt beobachtete Dienste automatisch freigeben** ausdrücklich aktiviert werden. Ohne diese Auswahl bleibt die Historie eine Vorschlagsliste.

Standard sind mindestens drei verschiedene historische Einsatztage pro Person und Dienst; die Schwelle ist von 2 bis 1097 Tagen einstellbar. Mehrere Einträge, Arbeitsplatzwechsel und Ist-/Soll-Duplikate am selben Tag erhöhen diese Zahl nicht. Arbeitszeitabweichungen werden nicht als eigenständiger Dienstnachweis verwendet.

Die Übernahme gilt dienstweit an allen Arbeitsplätzen, ausschließlich innerhalb des Planungs- und Beschäftigungszeitraums. Vorhandene Freigaben für denselben Dienst werden nicht erweitert oder ersetzt, insbesondere keine betreuten oder arbeitsplatzbeschränkten Freigaben. Persönliche Grenzen, Qualifikationen, Ruheprofile, Bedarfe und offene Importangaben bleiben unverändert.

Das Projekt protokolliert die gewählte Schwelle und die übernommenen Freigaben mit ihrer Evidenz. Die Historienansicht zeigt eine Zusammenfassung. Die Matrix bleibt bearbeitbar. Historische Häufigkeit ist kein Qualifikationsnachweis; die aktivierte Automatik ist eine ausdrücklich gewählte Vorbelegung, keine fachliche Prüfung. Für ältere Projekte ohne Tagesnachweise neu importieren.
