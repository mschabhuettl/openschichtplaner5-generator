# Version 0.9.27 – Hilfstexte besser lesen

Der vorhandene Farbwert für Sekundärtexte ist dunkler eingestellt. Davon
profitieren die Erklärungstexte zu Import, Einrichtung und Prüfung, die
Zusammenfassung der Projektanlage und schreibgeschützte Eingabewerte.
Texte, Navigation und fachliche Regeln bleiben unverändert.

Für den gemeinsamen Farbwert steigt das rechnerische Kontrastverhältnis
auf weißem Grund von etwa 4,15:1 auf 6,04:1. Auch auf den hellen
Flächenhintergründen wird der Kontrast erhöht. Dies ist eine gezielte
Verbesserung der Lesbarkeit, keine vollständige Barrierefreiheitsprüfung.

Die Änderung wird im vorhandenen synthetischen Desktop-/Mobilablauf geprüft
und anhand gleicher Vergleichsdienst- und Vorschauansichten visuell bewertet.
Veröffentlichung erst nach erfolgreichen [Release-Gates](verification.md).
Die Benutzerinstallation bleibt unverändert.
